# Tech Library — Бібліотека технічної літератури

Вебсервіс обліку технічної літератури на **Symfony 8.1** (PHP 8.4, Doctrine ORM, EasyAdmin 5, Twig, MySQL) та консольний клієнт на **Python**.

## Основні можливості

- **База даних (Doctrine ORM)**: пов'язані сутності `Topic` (`OneToMany`) та `Book` (`ManyToOne`), типізований перелік статусів `BookStatus` (`Enum`), серверна валідація полів, міграції схеми БД та оптимізовані запити через `QueryBuilder` (без проблеми N+1).
- **Публічний вебсайт (Twig)**: головна сторінка зі списком тематичних розділів та підрахунком кількості книг, сторінка розділу з фільтрацією за статусом наявності та пошуком за назвою, автором чи ISBN, детальна картка книги з анотацією.
- **Адмін-панель (EasyAdmin 5)**: повноцінний CRUD-інтерфейс для керування розділами та книгами, захищений автентифікацією та перевіркою ролі `ROLE_ADMIN`.
- **JSON API та Python-клієнт**: програмні маршрути для отримання списку розділів і книг у форматі JSON, а також консольний скрипт `client.py`, який перевіряє API та виконує автентифікацію в адмін-панелі через сесію (`PHPSESSID` + CSRF).

## Маршрути застосунку

| Маршрут | Метод | Опис |
| :--- | :--- | :--- |
| `/` | `GET` | Головна сторінка зі списком розділів та кількістю книг |
| `/topic/{slug}` | `GET` | Книги обраного розділу (підтримує фільтри `?status=` та `?q=`) |
| `/book/{id}` | `GET` | Детальна сторінка окремої книги |
| `/api/topics` | `GET` | JSON-список усіх розділів із кількістю книг |
| `/api/books` | `GET` | JSON-список усіх книг (підтримує `?status=` та `?q=`) |
| `/api/topics/{slug}` | `GET` | JSON-перелік книг конкретного розділу |
| `/login` | `GET`, `POST` | Сторінка входу адміністратора |
| `/admin` | `GET` | Закрита панель керування EasyAdmin 5 (`ROLE_ADMIN`) |

## Інструкція із запуску локально

1. **Клонувати репозиторій та встановити залежності PHP:**
   ```bash
   composer install
   ```

2. **Налаштувати підключення до бази даних MySQL:**
   Створити файл `.env.local` у корені проєкту та вказати рядок підключення:
   ```env
   DATABASE_URL="mysql://root:@127.0.0.1:3306/tech_library?serverVersion=8.4.3&charset=utf8mb4"
   ```

3. **Створити базу даних та застосувати міграції:**
   ```bash
   php bin/console doctrine:database:create --if-not-exists
   php bin/console doctrine:migrations:migrate
   ```

4. **Створити обліковий запис адміністратора та наповнити каталог тестовими даними:**
   ```bash
   php bin/console app:admin:create
   php bin/console app:seed
   ```

5. **Запустити локальний вебсервер Symfony:**
   ```bash
   symfony serve
   ```
   Сервіс буде доступний за адресою `http://127.0.0.1:8000/`.

6. **Запустити консольний клієнт на Python (в окремому терміналі):**
   ```bash
   pip install requests
   python client.py
   ```
